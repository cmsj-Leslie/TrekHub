# TrekHub Frontend

基于 **Vue 3 + Vite + Naive UI** 的前端单页应用。

## 技术栈

- Vue 3 (Composition API + `<script setup>`)
- Vite 8 (构建工具)
- Vue Router 4 (前端路由)
- Pinia 2 (状态管理)
- Naive UI (UI 组件库)
- Axios (HTTP 请求)
- Socket.IO Client (实时聊天)
- Leaflet (地图展示)
- Day.js (日期处理)

## 启动

```bash
npm install
npm run dev
```

开发服务器运行在 `http://localhost:5173`

## 构建

```bash
npm run build
```

详细说明请参考项目根目录 [README.md](../README.md)
